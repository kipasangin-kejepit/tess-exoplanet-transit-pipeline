# Data provenance

`tess_real_lightcurve.csv` is the light-curve input used for the WASP-18 prototype run. The data were retrieved from TESS via Lightkurve, using a SPOC product and the first available observation with default quality filtering. It has `time` and `flux` columns and is provided to support reproducibility of the reported pipeline run.

Time is expressed in BTJD (BJD - 2,457,000). The target is WASP-18, a known exoplanet-host system. The analysis is a method demonstration, not a new-planet claim.
